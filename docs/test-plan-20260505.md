## Known Gaps

1. **OOM recovery is silent** — system restart auto-recovers from SQLite but doesn't log that
   the previous run was OOM-killed. Acceptable for prototype.
2. **No real API integration tests** — all LLM calls are mocked. Add a `--live` flag for
   integration tests against real APIs once credentials are configured.
3. **TypeScript sandbox not tested** — the `test_sandbox.py` tests only exercise the Python
   runtime path. Add Jest-based sandbox tests when Node.js is available in CI.
